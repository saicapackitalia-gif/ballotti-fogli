# Foto di test

Cartella per le foto reali usate per validare il prototipo.

Per ogni foto che aggiungete, indicate qui sotto (o nel nome del file) almeno:

- **profilo onda** (B, E, C, EB, BC...)
- **larghezza nota di una fila** in mm, e se sono più file affiancate legate
  insieme quante (`--rows`)
- **conteggio manuale reale**, se disponibile, per confrontarlo con la stima
